## Overview

This portfolio website serves as a digital resume and project showcase, designed to present professional capabilities in software development and user interface design.

Built with a focus on performance, responsive design, and visual presentation, the website demonstrates the use of modern frontend technologies to create an engaging and interactive user experience.

The platform integrates interactive elements such as animated typing effects, dynamic project galleries, and multi-language support.

## Installation

### Prerequisites

Make sure you have the following installed:

* Node.js version 18 or later
* npm

### Clone the Repository

```bash
git clone https://github.com/alfrzimhmd/my-portfolio.git
cd my-portfolio
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

The application will be available at the local development URL displayed in your terminal.

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Key Features

### Hero Section

* Dynamic typing animation for the name and professional title
* Social media integration with GitHub, LinkedIn, and Instagram
* Technology stack badges
* Profile photograph with an animated frame

### About Section

* Professional biography and background summary
* Core competencies with descriptive icons
* Professional statistics, including:

  * Completed projects
  * Technology stack
  * Passion for development
  * Continuous learning
* Resume or CV download functionality

### Projects Section

* Responsive grid layout for project cards
* Automated image slideshow for each project
* Detailed modal view featuring:

  * Image gallery with navigation controls
  * Embedded video demonstrations where available
  * Comprehensive project descriptions
  * Technology stack tags
  * Project feature lists
  * GitHub repository links
  * Live demo links
* Visual indicators for projects with video demonstrations

### Skills Section

* Floating technology icons with rotation effects
* Skill proficiency bars with percentage indicators
* Modern glassmorphism card design

### Contact Section

* Toggle between WhatsApp and Email contact methods
* Dynamic form fields based on the selected contact method
* Direct integration with messaging platforms

### Footer

* Personal brand information
* Quick navigation links
* Social media links with interactive tooltips
* Copyright notice with subtle animations
